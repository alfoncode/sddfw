A LITTLE MORE CONTEXT

Good questions.

Can I install SDDFW yet?+

The framework is in early development. This landing includes a working interactive sample of the acceptance report. The v0.1 roadmap shows what we plan to implement first.

Will I need to change my coding agent?+

The goal is to fit your existing workflow. SDDFW will provide the specification and acceptance loop while your coding agent handles implementation. We’ll start with a focused integration and expand through real use.

What does a passed check actually mean?+

A specific check succeeded for the recorded version and environment. The report should make that scope explicit. Missing checks remain unverified, and local results are identified as local results.
